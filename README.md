# EcoSort AI

AI-powered waste segregation assistant built using HTML, CSS and JavaScript.

## Features

- Classifies common waste items
- Identifies recyclable and non-recyclable waste
- Provides disposal recommendations
- Simple and responsive interface
- Ready for GitHub Pages deployment

## Technologies Used

- HTML5
- CSS3
- JavaScript
